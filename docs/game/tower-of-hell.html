What is Tower of Hell?

Can you be the first to the top in this randomly generated obby with absolutely no checkpoints at all? Owners of VIP-Servers can use the settings menu to skip rounds, set the tower size and lock the shop.

Made by YXceptional Studios, first released 8 years ago, 29.4B total visits, up to 20 players per server.

Description written by the game's own creators and shown on Roblox.
