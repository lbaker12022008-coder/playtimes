Why are there so many?

There are 75 games on this list and only 73 that are growing. That is about the games we watch, not about Roblox.

We add a game when it turns up on Roblox’s own charts, and a game usually gets there by suddenly becoming popular. Most of them drop back again afterwards, so our list catches a lot of games on the way down.
